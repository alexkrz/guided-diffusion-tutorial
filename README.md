# Guided Diffusion

This repository contains restructured code from the great guided-diffusion tutorial at <https://www.kaggle.com/code/vikramsandu/guided-diffusion-by-openai-from-scratch>.

The original repository from OpenAI is here: <https://github.com/openai/guided-diffusion>.

## Setup

We recommend [miniforge](https://conda-forge.org/download/) to set up your python environment. \
Then [uv](https://docs.astral.sh/uv/) can be used to install the project dependencies:

```bash
conda create -n $YOUR_ENV_NAME python=3.12
conda activate $YOUR_ENV_NAME
uv pip install -r requirements.txt
```

## Getting started

The config for training and evaluation is located at [src/config.py](src/config.py).

Training can be performed by running

```bash
python train.py
```

The training script will save checkpoints for the Unet and the Unet-Classifier in the `logs/` directory.

After the checkpoints are saved, images can be generated by running

```bash
python generate.py
```

Generated images will be stored in the `results/` directory.
